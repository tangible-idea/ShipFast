Ship your mobile app to Google Play and the App Store

An agent skill that takes any mobile app from source to a store submission. Real-device screenshots, every store image, an evidence-based privacy policy. No mockups.

npx skills add tangible-idea/ShipFast --skill shipfast
InstallView on GitHub

Ask your agent in plain words

Works with Flutter, Expo, React Native, Capacitor, native Android and native iOS.

/shipfast launch Android app on Play Store

Detect, signed build, real-device run, closed test, listing, review.

/shipfast launch ios

The same flow for App Store Connect.

/shipfast images ios

iPhone screenshots plus Product Page Header and Search Results images.

/shipfast icon

Three SVG concepts, then iOS 1024px and Play 512px icons.

/shipfast resume

Continue from what was saved in .shipfast/.

Every store image, from your real build

Play phone screenshots and feature graphic. iPhone screenshots, Product Page Header (21:9), Search Results (3:2) and universal 16:9 images. You confirm each capture before it is used.

A privacy policy that matches your code

Data and privacy declarations are filled from evidence in your app, never copied from another one. Missing privacy policy and terms pages can be generated and uploaded to Firebase Hosting.

Every item is tracked

Each step is recorded in .shipfast/ in your app, from prepared to submitted, approved and public, so an interrupted release resumes where it stopped. It never asks for your password: you sign in to the console yourself.

Install

Works with any host that reads Agent Skills, including Claude Code, Cursor, Codex and Gemini CLI.

npx skills add tangible-idea/ShipFast --skill shipfast

Or as a Claude Code plugin (Claude Code 2.1.275 or later):

/plugin install shipfast --marketplace tangible-idea/ShipFast

The renderers use sharp. Install it once inside the installed skill folder:

npm install --prefix ~/.claude/skills/shipfast
